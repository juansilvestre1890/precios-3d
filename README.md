# Precios 3D

Aplicación web (PWA) para calcular costos y precios de venta de productos de impresión 3D.

- Publicada con GitHub Pages: https://juansilvestre1890.github.io/precios-3d/
- Datos guardados en Google Sheets mediante Google Apps Script.
- El enlace del backend se configura en `js/config.js`.
